# Changelog

## 0.2.0 (2026-11-13)

- New: `SpecStreamResearch` gives a Pipecat agent written research reports from the live web, with the page behind each cited sentence, as three tools: `specstream_research_price`, `specstream_start_research` (an async function call) and `specstream_get_research`.
- New example: `examples/research.py`.
- Tested with Pipecat v1.16.0.

## 0.1.0 (2026-11-12)

- First release. `SpecStreamDeepSearch` gives a Pipecat agent five tools: `specstream_web_search`, `specstream_read_pages`, `specstream_price_list`, `specstream_find_list` (an async function call) and `specstream_get_list_results`.
- Tested with Pipecat v1.16.0.
